# KedaiPOS - Sistem Inventori & Jualan

Sistem ini dibina menggunakan React (Frontend) dan Node.js/Express dengan SQLite (Backend) untuk memberikan pengalaman aplikasi desktop yang moden di dalam pelayar web.

## Cara Menjalankan (Tempatan)
Jika anda ingin menjalankan aplikasi ini di komputer anda sendiri:
1. Pastikan anda mempunyai **Node.js** dipasang.
2. Salin fail projek ini.
3. Jalankan `npm install` untuk memasang dependensi.
4. Jalankan `npm run dev` untuk memulakan pelayan.

## Nota Mengenai Python + Tkinter
Walaupun persekitaran ini dioptimumkan untuk aplikasi web, saya telah menyertakan fail `pos_app.py` yang mengandungi kod Python + Tkinter seperti yang diminta. Anda boleh memuat turun fail tersebut dan menjalankannya secara tempatan menggunakan perintah:
`python pos_app.py`

## Data Ujian
Aplikasi ini akan memulakan pangkalan data dengan beberapa produk contoh:
- Roti Putih (RM 3.00)
- Susu Segar (RM 7.50)
- Telur Gred A (RM 13.50)
- Beras 5kg (RM 26.00)
